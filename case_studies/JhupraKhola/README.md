## JhupraKhola Case Study

The first detailed case study focuses on the **JhupraKhola River Basin / JhupraKhola area** in Karnali Province, Nepal.

The case study is intended to investigate settlement transformation, river–settlement relationships, historical landscape change, and potential water-related hazard/exposure characteristics using documented geospatial and remote-sensing evidence.

The case-study directory is:

```text
case_studies/JhupraKhola/
```

Potential contents include:

* Historical imagery
* Recent imagery
* Satellite imagery
* Permitted Google Earth imagery/screenshots
* Basin boundary
* River network
* Settlement boundaries
* Buildings
* Roads
* Settlement observations
* Historical change analysis
* River-proximity analysis
* Hazard/exposure analysis
* Maps
* Figures
* Tables
* Metadata
